# Мастер прогулов — Лабораторная 3

Консольное приложение по задаче «Мастер прогулов 80-го уровня» из курса «C# и платформа .NET».
Условие: https://sites.google.com/view/fitnsudotnet

Программа работает постоянно: каждые 5 секунд проходит учебный день (6 пар в день),
после каждого дня печатает общее удовольствие и среднее удовольствие в день.
Прогон бесконечный - программа прерывается при вылете или по ctrl+c.
Ключевая логика (правила опроса, эмулятор дня и семестра, история наблюдений, стратегия)
покрыта модульными тестами (xUnit + Moq), рандом в тестах подменяется фейковым источником.

Как устроена задача:
- у каждого преподавателя в начале семестра случайно выбирается одно из трех правил опроса:
  спросить с вероятностью 50%, спросить если вчера спросили по предмету A,
  или спросить по правилу «A xor Б»;
- прогул пары и пирожок дают по 1 баллу удовольствия, пирожок студент ест каждый день;
- если студент прогулял пару и его спросили — он вылетает, все удовольствие обнуляется.

Стратегия смотрит на историю наблюдений: прогуливает пару, если в последний посещенный
день по ней не спрашивали, поэтому вылет возможен.

Баллы (удовольствие): прогул пары и пирожок дают по 1 баллу. Максимум за день — 7 баллов
(6 прогуленных пар + пирожок), и он достигается только если прогулять все пары
и не быть спрошенным ни на одной из них. Если спросили на прогуленной паре —
вылет, все баллы за семестр обнуляются.

## Что смотреть

Запуск и жизненный цикл:

- `SkipMaster.Host/Program.cs` — точка входа: Generic Host, регистрация сервисов через di;
- `SkipMaster.Host/SemesterHostedService.cs` — фоновый цикл: день -> лог -> пауза,
  остановка по Ctrl+C и при вылете;
- `SkipMaster.Simulation/SimulationOptions.cs` + `SkipMaster.Host/appsettings.json` —
  настройки (длительность дня).

Логика задачи (без изменений, кроме шагового режима раннера):

- `SkipMaster.Domain/Rules/` — три правила опроса (RandomAskRule, DependOnSubjectRule, XorSubjectsRule);
- `SkipMaster.Simulation/RuleGenerator.cs` — генерация правил преподавателей на семестр;
- `SkipMaster.Simulation/TeacherProvider.cs` — шесть преподавателей со сгенерированными правилами;
- `SkipMaster.Simulation/DayGenerator.cs` — один учебный день (решения, опросы, начисление баллов, вылет);
- `SkipMaster.Simulation/SemesterRunner.cs` — прогон семестра по шагам, обнуление при вылете;
- `SkipMaster.Simulation/DefaultRandomSource.cs` — весь рандом приложения в одном месте;
- `SkipMaster.Strategies/LastOutcomeStrategy.cs` — стратегия «прогул, если в последний раз не спрашивали».
- `SkipMaster.Tests/` — модульные тесты (xUnit + Moq); `FakeRandomSource.cs` подменяет рандом
  заданными значениями, тесты детерминированы.

## Что изменено относительно предыдущей лабы

- Программа переведена на Generic Host - сервисы регистрируются через di, а не собираются вручную в Program.cs.
- Дни пошли в фоновом сервисе (SemesterHostedService): один день раз в 5 секунд, после каждого дня - общее и среднее удовольствие. Выход - по Ctrl+C или при вылете студента.
- SemesterRunner стал шаговым (MakeStep) - в первой лабе он прогонял весь семестр за один вызов, теперь приложение живет постоянно.
- Задержка дня переехала из кода в appsettings.json.
- Появился проект тестов SkipMaster.Tests: детерминированный FakeRandomSource и 39 тестов правил опроса, генератора правил, эмулятора дня и семестра, истории наблюдений и стратегии.
- Правки по замечаниям после лаб 1-2: xml-комментарии у классов, primary constructors, «вчера» - массив флагов по предметам вместо шести отдельных полей.
- AlwaysAttendStrategy заменена на LastOutcomeStrategy - решение по каждому предмету на основе истории наблюдений, вылет стал возможен.
